1) Arithmetic Operators:
=============================
	1.1 + --- Addition
	1.2 - --- Substraction

	1.4 / --- Division
	1.5 % --- Modulas
    1.6 ** --- Power
    1.7 // --- Floor
   
2) Relational Operators:
=========================
	< --- less than
	> --- Greater than
   <= --- Less than or equal 
   >= --- Greater than or equal
   == --- Equals to
   != --- Not equals to
   
3) Assignment Operators:
===========================
   = --- Assign
  += --- Addition and Assign
  -= --- Substraction and Assign
  *= --- Multiplication and Assign
  /= --- Division and Assign
  %= --- Modular Division and Assign
 //= --- Floor division and Assign
 **= --- Power and Assign
 
4) Logical Operators:
===========================
  and : If both conditions are true then returns true in remaining all cases returns false
  or : If both the condisions are false then returns false in remaining all cases returns true
  not: returns true if the condition is false and vice versa.
  
5) Membership Operators:
=============================
 Membership operators used to check that the value or element is present into the given sequence or nothing
 in : return true if the value is present into the given sequence.
 not in: return true if the value is not present into the given sequence.
 
6) Identity Operators:
=========================
 Identity operators are used to check whether variables or objects having same identity or not.
 is: Returns true if the values or variables having same identity else returns false.
 is not: Returns true if the values or variables are not having same identity else return false.
 *** id() is the built-in function that used to get the memory address of mentioned variables.

Abstract Method:
=====================
A method which don't contain any implementation but contains only declaration is called Abstract Method.
To make a method as abstract we should use @abstractmethod decorator.
To leave an abstract method with no implementation then we must use pass keyword.
As a programmer if we don't know the implementation but we know the declaration then we should go for Abstract Method.

Abstract Class:
======================
A class which is having one or more Abstract methods called as Abstract Class.
Abstract class also contains non abstract methods like normal methods.
To make any class as Abstract class, that class must inherit from predefined abstract class called i.e ABC(Abstract Base Class)
We cannot create object for Abstract class directly. To create object for Abstract class we must create one Child class and then create the object for that child class.
Partial implementation of the class is called Abstract Class.
****ABC and abstractmethod decorators must be present in abc module***

Exception Handling:
--------------------------
Exception handling is nothing but error handling.
In general we do write and execute the code but during this time there may be a chance of different types of error occurance.
There are two types of errors.
	1)Syntactical errors - Missing parenthesis, indentation errors
	2)Runtime errors - It is abnormal termination of program execution. Abnormal termination is nothing but unsuccessfull termination.
Runtime errors are nothing but exceptions.

There are two types off exceptions:
===========================================
	1)Logical implementation
	2)try except implementation
	
An unwanted and unexpected event will disturb the normal flow of program execution called Exception.
In python every exception is a class.
	1)Name error
	2)value error
	3)type error
	4)zero division error
	5)file not found error
	6)file exist error etc.
	
For all the above classes Exception is the super class. The above classes will come under Exception super class.

try except implementation:
===================================
syntax:
--------------
	try:
		statements -- risky code to be included here
	except:
		statements -- handling code to be included here
	finally: (It is optional in python)	-- Mandatory code
		statements
		
There are two types of except block.
	1)default except block - Except block without exception class
	2)specific except block - Except block with exception class 
	  Ex:
		except ZeroDivisionError as zde:
			print(zde)
			
***** When we wants to use combination of default and specific except block into the program then we must use default except block first then
followed by default except block. ****************

except (ZeroDivisionError, ValueErro) as e:
	statements.
		or
except Exception as e:
	statements
