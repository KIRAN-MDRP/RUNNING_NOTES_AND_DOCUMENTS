Router and Modem:
=======================
Router - It is a device which is used to establish network.
Modem - It is the bridge between our private network to public network. With the help of Modem we are able to connect internet.

Private IP and Public IP:
=======================================
Each server will have both Private IP and Public IP.
By using Private IP we can communicate with devices those are present on the same network.			
By using Public IP we can communicate with devices on different network.(Networks over a network)

NAT - Network Access Translator - It acts as bridge between Private IP and Public IP.
**** We use Modem to connect Public IP from Private IP at home. But internally those will take help from NAT ************

How NAT works?
NAT server having Private IP and Public IP. 
NAT used to convert Private IP to Public IP and vice versa.
NAT servers are maintained by ISP people.
For example from our laptop we are accessing youtube then the flow will be like below.
		1)First we send request to NAT server in order to get access of youtube.
        2)Now NAT server converts your laptop Private IP into Public IP.
        3)Youtube having public IP. So NAT server routes that request to Youtube through Public IP of NAT server.
        4)Anyway Public IP to Public IP possible right. So access will get provided.
        5)In reverse order NAT server converts Public IP to Private IP and provides access.

C Groups:
===================
	Docker C groups stands for Docker Control Groups
	It is controlling Memory, CPU, I/O and Disk etc.
	By default container has no resource constraint.
	To know about each container utilization use below command
		docker stats
	Once any container utilization reaches into maximum limit then docker host machine will get hanged.
	So we can controll Memory, CPU, I/O and Disk of each container through C Groups.
	We have two types of memories, those are RAM and HardDisk.
	Difference between these are, RAM is temporary memory where as Harddisk is the permanent memory.
	In linux we have two types are there like 
		First type of memory (RAM)
		SWAP memory = When original memory maximum limit reached then to keep docker host mahine up and running SWAP memory will be used.
		Generally SWAP memory will be 2 times more than RAM. For example if RAM is 2 GB, SWAP memory will be 4GB.

We do write manifest file and upload it into the master component of K8S.
