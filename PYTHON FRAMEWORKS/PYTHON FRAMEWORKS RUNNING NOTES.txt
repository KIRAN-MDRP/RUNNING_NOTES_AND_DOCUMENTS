5)It is open source high level framework
6)Official website is: www.djangoproject.com

8)MVT is one of the design pattern.
9)DRY - We do not repeat yourself
10)M - Model - Data access layer    - MY SQL or SQL Lite

CSS = Cascading Style Sheets:
===================================
CSS are used to add style for HTML elements or tags.
Styling includes colors, borders, direction etc.

syntax:
==============
selector{
	property1:value1;
	property2:value2
}

Ex:
===========
p{
	color:red;
	font-size:30px;
}

To apply these CSS on HTML tags we will make use of styling technologies.
We have three types of styling technologies.
1)Inline Style  - To apply styling for individual html elements. For this we have to use style attribute at that html tag level.
2)Internal Style - To apply styling for current html page for multiple html elements. For this we have to use <style>
3)External Style - To apply styling for multiple html pages at a time. For this purpose we have to create separate css file with extention .css

Style sheet priority:
===============================
On same html element we have applied all three.
	Then first priority will go to inline style only.
	The second priority will be decided based on order we mentioned in head tag.
	
CSS selectors:
---------------------
Totally we have 4 selectors.
	1)Element selector.
	
	2)id selector  #myid{
						 color: red;
							}   
				<h1 id="myid"> This is h1</h1>
	
	3)class selector : .classname{}
	
	           <h1 class="cls"> This is h1</h1>
	
	4)universal selector: *{
		color: green;
	}
				
Selector priority:
=========================
On same html element if we applied all these selectors then the priority will be:
	id selector is the first then after class selector and then element selector finally universal selector.
